# Как запустить «Мой немецкий» (один раз, ~15 минут)

## 1. Сайт (мини-апп)
1. GitHub → репо **mein-deutsch** → **Settings** → **Pages**.
2. Source: **Deploy from a branch** → Branch: **main**, папка **/ (root)** → **Save**.
3. Подожди 1–2 минуты. Адрес сайта: https://1f8t8graf4-ai.github.io/mein-deutsch/

## 2. Бот в Telegram
1. Напиши **@BotFather** → `/newbot` → придумай имя (например «Мой немецкий») и ник (должен кончаться на `bot`).
2. BotFather пришлёт **токен**. Скопируй его, **но никому не присылай — и мне тоже**.

## 3. Воркер бота в Cloudflare (как у dota, только новый)
1. Cloudflare → **Workers & Pages** → **Create** → **Create Worker**. Имя: **mein-deutsch-bot** → **Deploy**.
2. **Edit code** → удали всё → вставь целиком файл `bot/worker.js` из репо → **Deploy**.
3. **Storage & Databases** → **KV** → **Create** → имя `mein-deutsch` → Create.
4. Воркер **mein-deutsch-bot** → **Settings** → **Bindings** → **Add** → **KV namespace**:
   - Variable name: `KV`;
   - namespace: `mein-deutsch`;
   - Save.
5. **Settings** → **Variables and Secrets** → **Add** (три раза):
   - тип **Secret**, имя `BOT_TOKEN` — токен из BotFather;
   - тип **Secret**, имя `SETUP_SECRET` — любое слово-пароль, например `kartoffel42`;
   - тип **Text**, имя `APP_URL` — `https://1f8t8graf4-ai.github.io/mein-deutsch/`.
6. **Settings** → **Triggers** → **Cron Triggers** → **Add**: `0 * * * *` (каждый час) → Add.
7. Открой в браузере `https://mein-deutsch-bot.1f8t8graf4.workers.dev/setup?secret=` и допиши в конце адреса своё слово-пароль. Должно быть `"ok":true`.

## 4. Проверка
- Открой своего бота → `/start` → кнопка **«Открыть «Мой немецкий»»**.
- В приложении: ⚙ → «Напоминание в боте» → выбери время → должно появиться «Напомню в …».
- Если воркер назвал иначе, чем `mein-deutsch-bot`, скажи мне адрес — я поправлю его в приложении.
